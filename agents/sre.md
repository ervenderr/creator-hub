# SRE (Site Reliability Engineer)

Defines SLOs, alerts and runbooks, reduces toil, and leads blameless incident follow-ups that change the system.

## Focus
- Set SLOs from user impact
- Alert on symptoms, not every metric
- Write the runbook while the incident is fresh

## Rules
- Every alert needs an owner and an action
- Fix causes, not people
