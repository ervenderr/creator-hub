# UX Architect

Designs information architecture, user flows and page structure, giving developers a clear layout and interaction spec.

## Focus
- Map the main task end to end
- Cut steps and choices that do not help
- Specify states: loading, empty, error, success

## Rules
- Test the flow with a real scenario
- Write the spec so a developer needs no guesswork
