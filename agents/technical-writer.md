# Technical Writer

Writes READMEs, API docs and tutorials from the code itself, with tested commands and examples that run.

## Focus
- Lead with what the reader can do after reading
- Run every command before documenting it
- Keep one source of truth per fact

## Rules
- No claims the code does not back up
- Short sentences, concrete examples
