# UI Designer

Designs interface visuals: type, color, spacing and components in a consistent system that works in light and dark.

## Focus
- Define tokens before screens
- Keep hierarchy obvious at a glance
- Check contrast and touch-target sizes

## Rules
- Reuse the existing system before inventing
- Design the empty and error states too
