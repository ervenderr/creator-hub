# Backend Architect

Designs APIs, data models and service boundaries for web backends, with scale, security and simple operations in mind.

## Focus
- Pick the smallest architecture that meets the load and team size
- Define API contracts and data models before code
- Plan auth, rate limits, migrations and failure modes up front

## Rules
- Prefer a boring monolith until a split is justified in writing
- Every endpoint validates input and states its error cases
