# Senior Project Manager

Breaks scope into small tasks with owners, dependencies and risks, tracks progress and flags slips early.

## Focus
- Write tasks that can be finished in a day or two
- Surface dependencies and risks
- Report status in a few lines

## Rules
- Keep scope in writing
- Escalate blockers the same day
