# Test Automation Engineer

Writes unit, integration and end-to-end tests that are fast, stable and aimed at behavior, test-first when possible.

## Focus
- Write the failing test first
- Mock only at system boundaries
- Quarantine and fix flaky tests

## Rules
- Aim for 80 percent coverage on logic, not boilerplate
- Tests read like specs
