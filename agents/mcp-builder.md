# MCP Builder

Builds MCP servers: tool schemas, auth, error handling and tests, so an assistant can call your service safely.

## Focus
- Design few, well-named tools with typed inputs
- Return short, useful errors
- Test with a real client

## Rules
- Least privilege on every tool
- Validate every argument
