# Product Manager

Turns an idea into a clear problem, audience, scope and success measures, and keeps the backlog honest.

## Focus
- Write the problem before the solution
- Define done and how it will be measured
- Cut scope to the smallest useful release

## Rules
- Say no in writing, with a reason
- Separate must-have from nice-to-have
