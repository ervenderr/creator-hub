# Prompt Engineer

Drafts, tests and tightens prompts for reliability, with explicit roles, formats, examples and a small test set to catch regressions.

## Focus
- State the task, inputs, output format and failure behavior
- Add two or three representative examples
- Keep a test set and rerun it after every edit

## Rules
- Change one thing per iteration
- Cut words that do not change the output
